# 스터디 PDF — PDF 학습자료 기반 학습·문제풀이 플랫폼

PDF 학습자료를 올리면 **Claude AI가 학습 노트·문제·해설을 자동 생성**하고, 학생은 그 자료로 학습 → 문제 풀이 → 채점 결과·문항별 해설 확인까지 할 수 있는 웹 서비스입니다. 관리자는 학생별로 발송한 학습자료와 풀이 결과를 모두 확인할 수 있습니다.

## 주요 기능

### 관리자
- **학습자료 업로드**: PDF(최대 32MB) 업로드 → AI가 요약·핵심 개념·학습 노트·문제(객관식/단답형)·해설 생성
  - 문항 수, 출제 요청사항(예: "3장 위주로") 지정 가능 / 다시 생성 가능
  - 생성된 학습 노트와 문항은 직접 수정·추가·삭제 가능
- **학생 관리**: 학생 계정 생성, 비밀번호 초기화, 삭제
- **발송**: 자료 화면에서 여러 학생에게 한 번에 발송하거나, 학생 화면에서 자료를 골라 발송 (마감일·메시지 선택)
- **결과 확인**
  - 대시보드: 전체 현황, 최근 제출
  - 학생별: 받은 자료 목록, 학습 상태(미학습/학습 중/풀이 완료), 최근·최고 점수, 회차별 풀이 기록
  - 자료별: 발송한 학생 전체의 진행 상태와 점수
  - 풀이 상세: 문항별 학생 답안·정답·해설

### 학생
- 받은 학습자료 목록과 진행 상태
- 학습 화면: AI 학습 노트(요약/핵심 개념/본문) + 원문 PDF 보기
- 문제 풀이: 응답 진행률 표시, 미응답 확인
- 채점 결과: 점수, 문항별 정답/오답, 내 선택과 정답 비교, 해설, 틀린 문제만 보기
- 여러 번 다시 풀기 가능(모든 회차 기록 보존)

> 문항을 나중에 수정해도 이미 제출된 풀이 결과는 제출 당시 문항 그대로 보존됩니다.

## 실행 방법

Node.js **22.13 이상**이 필요합니다(내장 SQLite 사용, 별도 DB 설치 불필요).

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # AI 자동 생성용 (없으면 수동 작성 모드)
npm start                             # http://localhost:3000
```

최초 실행 시 관리자 계정 `admin / admin1234` 가 만들어집니다. 로그인 후 **[내 계정]에서 비밀번호를 꼭 변경**하세요.

### 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (없음) | Claude API 키. 없으면 AI 생성이 꺼지고 노트·문항을 직접 작성 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 생성에 사용할 모델 |
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` | DB(`app.db`)와 업로드 PDF 저장 위치 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | `admin` / `admin1234` | 최초 관리자 계정 |
| `COOKIE_SECURE` | `false` | HTTPS 배포 시 `true` |

## 사용 흐름

1. 관리자 로그인 → **학생** 메뉴에서 학생 계정 생성
2. **학습자료** 메뉴에서 PDF 업로드 → AI 생성 완료까지 대기(자동 새로고침)
3. 생성된 노트·문항 검토/수정 → 학생 선택 후 **발송**
4. 학생 로그인 → 학습 → 문제 풀기 → 채점 결과와 해설 확인
5. 관리자는 대시보드·학생 상세·자료 상세에서 결과 확인

## 구조

```
src/
  server.js        실행 진입점(환경 변수, 관리자 계정 생성)
  app.js           Express 앱, 로그인/계정
  routes/admin.js  관리자 기능
  routes/student.js 학생 기능
  generator.js     Claude API로 PDF → 학습 노트·문항 생성(구조화 출력)
  grading.js       채점(객관식, 단답형 정규화 비교)
  db.js            SQLite 스키마
views/             EJS 템플릿
public/style.css   스타일
test/              테스트 (npm test)
```

## 참고

- 단답형은 공백·대소문자·문장부호를 무시하고 허용 정답 목록과 비교합니다. 동의어(예: `이산화탄소 | CO2`)는 정답 칸에 `|`로 구분해 추가하세요.
- AI 생성 비용은 PDF 분량과 문항 수에 비례합니다. 생성은 업로드·다시 생성 시에만 실행됩니다.
- 운영 배포 시 HTTPS 뒤에서 실행하고 `COOKIE_SECURE=true`를 설정하세요. `data/` 폴더는 정기적으로 백업하세요.
